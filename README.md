### x86 Disassembler

- Project to teach myself the basics of disassembly and the process of designing an ISA representation layer.
- Goal is to make a working, mostly fully functional disassembler in C (without AI beyond clarifying some conceptual issues)

## TO BUILD

`make test` to build "test" executable which we will then disassemble.
`make` to build "dis" executable.
`make run` to run "dis" with "test" as an input.
