### x86 Disassembler

- Basically just a project to teach myself the basics of disassembly.
- Goal is to make a working, mostly fully functional disassembler in C (without AI beyond clarifying some conceptual issues - as a note, youcan tell a human wrote this based on its poor structure and generalizability)

## TO BUILD

`make test` to build "test" executable which we will then disassemble.
`make` to build "dis" executable.
`make run` to run "dis" with "test" as an input.
